# LumeFetch v0.2.1 — public source preview

One downloader. Many platforms. Open source.

Maintainer: [Ranbon-Kafa / ruzgarefe.com](https://ruzgarefe.com)
License: MIT. Copyright © 2026 Ranbon-Kafa (https://ruzgarefe.com) and LumeFetch contributors.

## Included

- Modern Avalonia desktop interface, Turkish and English.
- YouTube, Instagram, TikTok, X, Reddit and direct-media adapters.
- MP3 audio output, video quality selection and FFmpeg processing.
- Managed queue: progress, pause/resume, cancel/retry and bounded concurrency.
- YouTube playlist selection and MP3 batch output.
- Experimental Spotify metadata → reviewed YouTube matching. Own Client ID and
  PKCE login required; no Spotify audio is downloaded.
- Project cover, logo, Windows icon, contributor/issue templates and CI.

## Verification

76 unit tests pass locally. Real local-media smoke verifies HTTP downloads,
FFmpeg merging, M4A and MP3 audio codec/container, and ID3 metadata.
Headless UI checks cover matching, playlist MP3 selection, language switching
and cancellation. OAuth callback/refresh is verified with a mock token server.
These are not clean-machine installer or real Spotify-account acceptance tests.

## Downloads

This release intentionally publishes **source code only**. GitHub's source ZIP
and tar.gz are not runnable desktop installers.
Build instructions are in README.md. Windows packaging scripts are included,
but prebuilt bundles are withheld until third-party redistribution and installer
checks in docs/RELEASE-CHECKLIST.md are complete.

Only download media you own, are authorized to download, or whose terms permit
downloading. No DRM or access-control bypass is supported.
Spotify access, cross-service policy/branding review, signing, clean Windows
installation tests and live platform acceptance remain open.
