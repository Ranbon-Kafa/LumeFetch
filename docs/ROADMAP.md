# Roadmap

## v0.1 — usable foundation

- [x] Avalonia desktop shell and modern URL-first workflow
- [x] Provider registry and generic HTTP/media provider
- [x] Download queue with progress, pause, resume, cancel, and retry
- [x] FFmpeg service boundary and executable discovery
- [x] YouTube / YouTube Music provider
- [x] Instagram provider
- [x] TikTok provider
- [x] X / Twitter provider
- [x] Reddit provider
- [x] Settings persistence and configurable parallelism
- [x] Windows installer and portable preview artifacts
- [ ] Clean-machine installer validation and per-platform public-video acceptance tests
- [ ] Code signing and third-party source redistribution audit before public release

## v0.2 — catalog resolution

- [x] Resolver contract implementation
- [x] Spotify track, album, and permitted playlist metadata with PKCE
- [x] YouTube candidate search
- [x] Weighted matching with user confirmation thresholds
- [x] YouTube playlist selection and batch download preparation
- [x] Turkish/English localization and app branding
- [ ] Real Spotify developer-account acceptance and platform policy/branding review
- [ ] Live authorized playlist and match acceptance tests

## Later

- [ ] Sandboxed third-party plugin loader
- [ ] Application updater
- [ ] Queue persistence across restarts and partial-file cleanup UI
- [ ] Linux and macOS packages
- [ ] More translations and accessibility audit
